# Продукт

ВЫХОД помогает человеку с нестабильным доходом пройти состояния Critical → Stabilization → Exit → Buffer. Главный экран начинает с одного выполнимого действия, защищённого резерва и дневного ориентира. Онбординг собирает валюту, доступные деньги, подтверждённый доход, обязательные расходы, долги и резерв. Пользователь может проводить сверку и безопасно сравнивать what-if без изменения исходных данных.

В MVP нет банковской синхронизации, платежей, инвестиций, скоринга, семейных аккаунтов и production push.
